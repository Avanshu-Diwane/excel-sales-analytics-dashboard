# 📊 Super Store Sales Analytics Dashboard

An interactive and dynamic sales analytics dashboard built using Microsoft Excel to analyze sales performance and identify business trends.

## 📸 Dashboard Preview

![Super Store Sales Dashboard](dashboard-preview.png)

## 🎯 Project Objective

The objective of this project was to transform raw sales data into an interactive dashboard using **Pivot Tables, Pivot Charts, KPI Cards and Slicers**.

The dashboard allows users to explore sales performance across different **regions and years**, with KPIs and visualizations updating dynamically based on the selected filters.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Analysis
- Data Visualization

## 📊 Dashboard Features

- Dynamic **Total Sales, Average Sales, Transactions and Quantity** KPIs
- Sales analysis by **Shipping Mode**
- Transaction analysis by **Region**
- Monthly quantity trend
- Top 5 cities analysis
- Category-wise transaction analysis
- Customer segment analysis
- Interactive **Region and Year slicers**

## 🔍 Key Analysis

The dashboard helps explore:

- Regional sales and transaction patterns
- Monthly changes in quantity
- Category and customer-segment performance
- Shipping-mode distribution
- Top-performing cities

All visualizations and KPIs update according to the selected filters.

## 🚀 How to Use

1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Go to the **Dashboard** sheet.
4. Use the **Region** and **Year** slicers.
5. Explore the dynamically updated KPIs and charts.
